# 풍속 모니터링 시스템 (Wind Monitoring System)

사용자가 제공한 현황판 및 데이터 관리 화면 기획안(3개 페이지)을 기반으로 제작된 모니터 전용 관제 웹 애플리케이션입니다.

## 📌 주요 특징 및 요구사항 충족

1. **모니터 해상도 완벽 대응 (Full Resolution Responsiveness)**
   - FHD (1920×1080), QHD (2560×1440), 4K (3840×2160), 1600×900, 1366×768 등 다양한 데스크톱/관제 모니터 비율(16:9, 16:10 등)에 최적화
   - CSS `clamp()`, `vh`, `vw`, Flexbox/Grid 비율 설계를 적용하여 **첫 화면(1페이지 풍속 현황판)이 상하/좌우 여백이나 불필요한 스크롤바 없이 화면 전체에 깔끔하게 들어맞도록(100vh/100vw 피팅)** 구현

2. **3개 화면(페이지) 구성**
   - **1페이지: 풍속 현황판 (`#dashboard` / `page1.html`)**
     - 실시간 현재 풍속 대형 숫자 표시 (8.4 m/s)
     - 시간최대 (18.9 m/s) 및 일간최대 (13.0 m/s) 카드
     - 실시간 디지털 시계 (예: `2026년 10월 21일 10시 01분`)
     - 산업용 전광판 특유의 더블 프레임 테두리 박스 구조 정밀 재현
     - 설정된 호출 주기에 맞춘 실시간 풍속 데이터 갱신 시뮬레이션
   - **2페이지: 데이터 추출 (`#data` / `page2.html`)**
     - 상단 날짜 선택(`YYYY-MM-DD`), `조회`, `다운로드` 버튼 배치
     - 1분 단위 풍속 / 돌풍풍속 데이터 그리드 테이블 (헤더 고정 + 부드러운 스크롤)
     - **실제 CSV 다운로드 기능** (Excel 한글 깨짐 방지 UTF-8 BOM 처리)
   - **3페이지: 호출 시간 변경 (`#settings` / `page3.html`)**
     - 기획서 원본 레이아웃의 상단 바 및 호출 시간 변경 버튼 배치
     - 호출 주기 프리셋(1초, 5초, 10초, 30초, 1분, 5분, 10분) 및 사용자 직접 입력
     - 변경 시 1페이지 풍속 현황판의 갱신 주기에 즉시 동기화
     - 센서 통신 핑(Ping) 테스트 기능 및 통신 상태 모니터링

3. **부가 기능**
   - **단축키 지원**: 숫자키 `1`, `2`, `3`을 눌러 페이지 즉시 전환
   - **현황판 전용(키오스크) 모드**: 단축키 `K` 또는 상단 📺 버튼을 누르면 메뉴바가 숨겨지고 기획안과 100% 동일한 순수 현황판 전체화면 모드로 전환
   - **다크 / 라이트 테마 전환**: 관제실 야간 모니터링 대응
   - **전체화면(F11)** 버튼 제공

## 🚀 실행 방법

### 브라우저에서 바로 열기
웹 서버 없이 `index.html` 파일을 더블 클릭하여 크롬, 엣지(Edge), 웨일 등의 브라우저에서 바로 열 수 있습니다.

- **통합 시스템**: `index.html` (상단 탭으로 1, 2, 3페이지 자유 이동)
- **1페이지 단독**: `page1.html`
- **2페이지 단독**: `page2.html`
- **3페이지 단독**: `page3.html`
